# 【一院科普】胸痛、胸闷你了解吗？

> 更新时间：2026-09-17 (UTC+8)

1. 心脏疾病
病症特征：首先它的部位一般位于胸骨后，胸骨中下段1/3，或者是心前区，范围约手掌大小，它的性质是一种压迫感，或者是紧缩感，患者可以伴有出汗，也可以伴有放射，比如说除了心前区或胸骨后的疼痛，可以有咽部的疼痛，下颌的疼痛甚至是左肩、左上肢等等。休息或含服硝酸甘油有助于症状的缓解，心绞痛它发生心痛的程度一般比较轻，一般三五分钟就能缓解，当然也有的在十几分钟或是半小时以内。如果患者的血压低于90mmHg，一般不用硝酸甘油，因为硝酸甘油有强烈的扩血管降血压的作用，这时可以考虑给予速效救心丸舌下含服。但如果胸痛程度较重，超过30分钟就要高度怀疑心肌梗死因引起的胸痛。

2. 肺部疾病
病症特征：痛点不明显，且可能伴随咳嗽等症状。
肺部疾病要在影响到肋膜、或是压迫到神经的时候才会有疼痛感，所以疼痛的症状不太明显；另外，像是细菌感染、霉菌感染造成的肺炎，或是肺结核，因为肺部积痰，也会有胸部闷痛的感觉，但多少会伴随咳嗽、容易喘、呼吸困难等症状。

3. 胃部疾病
病症特征：胃病胸口痛通常是一种钝痛或隐痛，也可能是一种胀痛或压迫感。疼痛多发生在胸骨后面或胃区域，并且可能会向上扩散到胸部或腰部。而且胸口痛常发生在饭后尤其是大餐后，或者在空腹时。这是因为胃在进食时需要分泌胃酸和消化酶，这些物质可能会损伤胃黏膜，导致疼痛。还可能伴随其他症状，如消化不良、反酸、暧气、恶心、呕吐、食欲不振、便秘或腹泻等

4. 肌肉拉伤
病症特征：有明显的压痛点，而且改变姿势的时候会更疼痛。
如果剧烈运动时，不小心拉伤了胸部肌肉，由于肌肉受到损伤，患者会出现胸部疼痛的症状，而且这种疼痛属于体表痛，可以明确的找到痛点，如果改变姿势会更加疼痛或不痛。

5. 带状疱疹
病症特征：通常是在身体一侧的胸部出现疼痛和刺痛，可伴随着皮肤的烧灼感、痒和疱疹。疼痛可能是持续的、难以忍受的，也可能是阵发性的痛感。疼痛可能扩散到肩膀或手臂。带状疱疹是病毒侵犯神经，所以疼痛是会持续不断，变换姿势也不会改变疼痛，而且可以找到明显的压痛点。除了疼痛之外，还会有头痛、发烧等类似感冒的症状，经过2~3天开始出现红疹，进而形成一群群水泡。

6. 心理因素( 焦虑 )
病症特征：焦虑引起的胸痛通常被形容为闷痛或压迫感。与心绞痛相似的是，焦虑引起的胸痛通常是一种压迫性的疼痛，但与心绞痛不同的是，焦虑引起的胸痛往往会比较轻微，而且往往持续不久，持续时间一般在几分钟到十几分钟不等。一旦焦虑情绪得以缓解，疼痛感通常会迅速减轻或消失。而且胸痛常位于胸骨后部，或者在心脏区域，也可能波及到胸部两侧或肩部。然而，应该特别注意的是，焦虑引起的胸痛与其他严重的心血管疾病相关的胸痛有时会非常相似。这种情况下，最好就诊于专业医生，以排除其他潜在的健康问题。

小提醒：以上仅供参考，如果胸痛一直持续着，建议立即去医院就诊查找原因、明确诊断进行对症治疗，这样的治疗才是最有效的方法。
