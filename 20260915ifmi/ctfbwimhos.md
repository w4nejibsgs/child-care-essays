# 试管婴儿孕酮低怎么办

> 更新时间：2026-09-15 (UTC+8)

试管婴儿孕酮低怎么办更新时间:2020-07-17

孕酮低，会导致胎儿发育缓慢甚至、。因此孕酮对于补胎有着至关重要的作用。一般出现孕酮低的情况，就要及时到医院保胎，在医生的指导下打补充孕酮的针或者口服黄体酮来提高孕酮。那么试管婴儿孕酮低怎么办呢？下面让我们一起来详细了解一下。

​

1.服用黄体酮

一般孕妇孕酮低，都可以通过服用黄体酮进行补充。这是常见的补充孕酮的办法，足量的黄体酮能够促进胚胎的发育和生长，还能抗排异和抑制子宫收缩。但是黄体酮药物的使用要注意需要适量。否则也会对胎儿造成不好的影响。

2.打孕酮针

孕酮缺乏严重的时候，除了吃黄体酮，也可以通过打孕酮针来补充。部分孕妇对黄体酮有不良反应，也可以通过打孕酮针来补充。无论是孕酮针还是黄体酮，都一定要在医生的指导下使用。值得注意的是孕酮针和黄体酮不是适用于所有的孕酮低的，如果是母体疾病或者遗传因素导致的胎儿停育，就不适合用黄体酮或者孕酮针补胎。

3.饮食调理

孕酮低的孕妇，可以多补充一些含有天然孕激素的食物。如豆类和豆制品中含有天然的大豆异黄酮，就是我们平时常说的豆浆豆腐豆皮等。这对于补充孕酮也起到一定的效果。还有要多补充天然维生素E，这些可以从新鲜的蔬菜水果中摄入。像菠菜、草莓、猕猴桃这些蔬菜水果都有助于补充孕酮。

试管婴儿孕酮低的解决办法主要有以上三种，孕酮低一定要及时补充孕酮，否则胚胎停育的几率会非常大。除了补充后补充孕酮，孕妇在备孕的时候，就可以依靠中医调理好身体的激素，而且在备孕期间应该多运动，保持乐观的心情。
