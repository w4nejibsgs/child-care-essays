# 【公告】医改15日起全面启动，以后来院就诊务必携带本人身份证或医保卡！！！

> 更新时间：2026-09-11 (UTC+8)

我院从2017年7月15日零时起，启动城市公立医院综合改革方案，按市物价部门制定的医疗服务价格标准进行收费。

医改后挂号费将并入门诊诊查费。

覆盖全市各级各类公立医院

据了解，2015年底，我市3个县级市及原电白县根据省的要求，共8家县级医院进行了县级公立医院改革。茂名市政府及市府办于今年7月5日印发了《茂名市深化医药卫生体制综合改革实施方案》及《茂名市城市公立医院综合改革实施方案》，明确要求，自7月15日起，我市所有公立医院综合改革全面推开，原来未参加县级公立医院改革的各级各类公立医院，包括职防院、慢病院，事业单位、国有企业单位、军队、武警部队医院都要同步参加。7月15日起，全部取消药品加成（中药饮片除外），其中二、三（或相当于二、三级）医疗机构同步实行新的调整价格。一级医疗机构其他价格不作调整，普通门诊按照基层医疗机构一般诊疗费收费标准收费。

已参加县级公立医院改革的8家县级人民医院、中医院在原已取消药品加成政策的基础上，根据“同城同价”的要求，于7月15日起同时实行新的调整价格。

调整医疗服务价格

此次综合医改关于价格调整的重点内容，可以概括为：一取消，二并入，三调整，有升有降，总量不变。

一取消，是指取消公立医院的药品（中药饮片除外）加成；

二并入，是指将挂号费并入诊查费，将空调费并入床位费一并收取；

三调整，是调整医疗服务项目价格，涉及诊疗、床位、护理、手术、中医、检查治疗和检验。本次改革是属于医药费用的总量控制，结构调整。通过取消药品加成、降低大型设备检查及检验价格等措施，腾移空间，用于提高医护人员技术劳务价格。

提高诊查费、护理等综合服务类部分项目、部分病理检查和部分临床各系统诊疗、手术项目价格，六岁（含）以下儿童手术（含麻醉）部分项目加收20%。降低部分医疗服务项目价格，重点降低部分检验项目6%，降低磁共振扫描（MRI）、X线计算机体层(CT)等大型设备检查12%和部分以设备为主的辅助操作项目。

医改将提高医护人员技术劳务价格。

**本次调整将挂号费并入门诊诊查费统一收取（详见下表）**

普通门诊诊查费用明显下降

本次调整将挂号费并入门诊诊查费统一收取，门诊诊查费中分设普通门诊诊查费、名专家、副主任医师、主任医师诊查费、急诊诊查费。

从表格上可以看出，对于普通门诊的患者，门诊诊查费用明显下降，但对于高级别医院及医生的诊查费用，患者有不同程度的增加，但增加部分通过药品取消加成、降低检查、检验费用等减轻，总体上不会增加患者负担。

    “以一个2016年在三级医院就诊的病人为例，这位患者就医共需缴纳1236.06元，其中挂号费6.5元，药品费用604.83元，胸椎CT平扫费用586.5元，床边心电图费用38.23元。价格调整后，这位患者只需缴纳费用1077.42元，其中诊查费12.1元，假如有医保，则减少3元，药品费用减少15%后约为514元，胸椎CT平扫费用减少12%，为516.12元，心电图费用减少8%，约35.2元。总费用减少了约159元。”

将发挥医保基金的保障作用

医药服务价格调整后，将充分发挥医保基金的保障作用，纳入医保报销的医疗服务项目范围保持不变、报销比例保持不变，同时将进一步深化医保支付方式改革。整合普通门诊统筹基金和住院统筹基金，归并为医保统筹基金使用。我市基本医疗保险（含城镇职工医保和城乡居民医保）参保人在市内二、三级公立医院改革医院门诊就医的，可享受门诊诊查费定额报销待遇，报销标准为3元/人·次。

本市职工医保、城乡医保参保员在医保缴费正常情况下，到我院门急诊就诊，诊查费3元将由社保局现场报销，只需自付自己该给的余下的诊查费。温馨提醒：请务必携带本人身份证或医保卡喔~

温馨小提示：

一、医保报销对象：茂名地区城镇职工、城乡居民基本医疗保险参保人。

二、参保人挂号需要符合以下条件，才能享受医保报销诊查费3元/人次，只需付清个人自付部分的诊查费。

1、参保人本人就诊；

2、医疗保险正常缴费。

三、参保人挂号就诊时请出示社会保障卡或身份证或户口簿进行读卡登记，由收费员发送到社保系统核实参保身份。如查询个人基金“正常”，才能享受医保报销诊查费3元，否则全额缴交诊查费（如个人基金“冻结”）。详情请咨询社保局 2868510。

四、特殊人群的就医优惠政策保持不变。
