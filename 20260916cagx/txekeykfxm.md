# 家长注意丨1岁男孩突然口腔全部溃烂，口水流不停，原因竟是……

> 更新时间：2026-09-16 (UTC+8)

家住芦淞区的王女士有个一岁半的儿子睿睿，十分聪明活泼。前几日，正在厨房准备晚餐的王女士忽然听见儿子的哭声，跑到客厅一看，睿睿正在嚎啕大哭，口水不停地流，嘴巴里面像被烧烂了一样！王女士和老公赶紧抱着睿睿到株洲市中心医院急诊儿科就诊。

由于家长也不知道睿睿到底是吃了什么才会变成这样，一时间医生也不敢随意治疗。还好接诊医生有丰富的临床经验，仔细查看睿睿的口腔十分像被高锰酸钾所腐蚀，于是询问家长家中是否有这类化学物品。睿睿的奶奶忽然想起来以前确实买过pp粉，自己都不记得放到哪个屉子里了，竟然被一岁的孙子翻出来还误食。找到病因后，医生立即对症进行治疗，所幸就医及时，在观察了一晚后睿睿便出院。

据了解，株洲市中心医院每周都有因误食各种有害物而前来急诊的患儿，以1-3岁患儿最多，其原因和种类也是五花八门，常见的有如下几类：妇阴洁、足光粉、络合碘等外用药品或消毒剂；有机磷农药、老鼠药、洁厕灵、汽车香水等有毒化学物质；纽扣电池、硬币及耳钉各种小饰品等小物件；高血压、心脏病、糖尿病等老年人需要长期服用的药物以及味道比较好吃的儿童药品等等。

小儿急性中毒的原因大多由于患儿年幼好奇，缺乏生活经验，一些药品的色彩、形状及甜味糖衣对他们都有极大的吸引力，如果储存不当，孩子容易把药片当作好吃的糖豆而致误食。

**儿童急性中毒病情凶险，却可以预防。因此积极做好安全教育尤为关键。**

1、家长或保育人员对幼儿或儿童要加强看管，监护人要提高安全防范的意识，教育小孩不随便捡东西吃，吃东西前应先询问家长，待允许后才可以吃。

2、成人药和儿童药要分开，外用药与口服药要分开，更不要把药品和其他物品（尤其是食物）混放在一起，以免拿错造成误服。

3、药品放置在高处，儿童看不到也摸不到的地方，切勿将药品随意放在桌柜上，枕边或儿童容易拿到的抽屉里。尤其危险物品 ( 有毒物体或药物 ) 应放置在小孩拿不到的地方。

  

 4、让家里的老人认识儿童用药安全重要性非常有必要，同时也是儿童药物误服不可少的预防措施。孩子生病若需要老人帮忙服药时，家长一定要在嘱咐的同时，用较大的字写下服用剂量和时间，并到了给孩子喂药的时间，打电话再次提醒。

**儿童误服处理流程：**

1、发现孩子误服家长一定要冷静对待，事情已经发生，打骂解决不了任何问题，先弄清孩子吃了什么，吃了多少是关键。

2、一般的药物比如过量误服维生素、止咳糖浆之类；副作用比价大的药物，比如说降压药、镇静药等可以用手指刺激小孩咽部，使孩子呕吐，以排除药物（催吐在4-6小时内有效）。初步处理完后立即送去医院进一步处理。

3、如服用了有毒的药物或者孩子出现了昏迷、抽搐，要立即送去医院，由医生来处理。

4、家长去医院的时候最好带上误服物品的外包装以及说明书。

5、根据情况可以适量口服阻碍毒物吸收的如牛奶、蛋清、等饮品，因其能分别与不同毒物发生沉淀作用，可延缓其吸收。
