# 宜都不孕不育医院有哪几家能做试管？

> 更新时间：2026-09-19 (UTC+8)

结婚三年了，从未怀过。然后我平时月经量大，有血块，月经不规律。我感觉可能就是这个原因，所以就在去年12月做了一系列检查，查出有子宫息肉，输卵管疑似积水，还有多囊，上周五又在我们宜都本地的一家大医院做四维超声造影检查，确认了有左侧输卵管积水。医生给我的意见是先做通液手术，然后再做试管。想问问本地的不孕不育姐妹们，要做试管的话，可以去哪里做？求推荐附近可做试管的医院。

目前宜都并没有不孕不育医院，该市的宜都市第一人民医院、宜都市中医医院、宜都市第二人民医院、宜都市妇幼保健院等等，都还未获得开展辅助生殖技术的资质，所以在宜都市做不了试管婴儿。宜都市的不孕不育患者想要做试管婴儿，可以前往湖北省其他市，比如武汉市，就有10家可做试管的医院，荆州市、十堰市和宜昌市各有2家，襄阳、天门、黄石、荆门各1家。

宜都目前由宜昌市代管，宜都北与宜昌市接壤，东隔长江与宜昌市猇亭区、枝江市相望，东南邻松滋市，宜都市临近的这些市区就只有宜昌有可做试管的医院，同省其他市相对之下要近一点的还有荆州市和荆门市，下面为大家介绍一下宜都市附近市区可做试管的医院：

- 1. 宜昌市中心人民医院，位于宜昌市夷陵大道183号，现在开展了第一代和第二代试管婴儿技术；
- 2. 三峡大学附属仁和医院，位于宜昌市伍家岗区夷陵路410号，也开展了第一代和第二代试管婴儿技术；
- 3. 荆州市中心医院，位于荆州市荆州区荆中路60号，现目前能做第一代和第二代试管婴儿；
- 4. 荆州市第一人民医院，位于荆州市沙市区航空路8号，现目前也能做第一代和第二代试管婴儿；
- 5. 荆门市第二人民医院，位于荆门市东宝区象山大道39号，也有第一代和第二代试管婴儿技术。
以上就是宜都附近可以做试管婴儿的医院，这些医院都可以做一二代试管，但若是需要做三代试管的话，就近考虑就要去武汉才可以，目前武汉可做三代试管的医院有武汉协和医院、武汉同济医院、湖北省妇幼保健院和武汉大学人民医院。
